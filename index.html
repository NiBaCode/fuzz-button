Fuzz Button

A real button covered in hair. Press it. One file, no libraries.

Download the file

Use it

Paste the code into any page, then place the tag where you want the button. Change the words, colours and size here:

<fuzz-button label="Get started" color="#FFB000" text-color="#090A0C" width="320" height="110"></fuzz-button>

Good to know

It works like a normal button: click, keyboard and touch. Listen for click as usual.

It needs WebGL2. Without it, you get a plain button. Slow devices get a thinner coat automatically.
