Make your own button covered in hair.

Text colour

Use it

  1. Choose your text and colours above.
  2. Press Copy the code.
  3. Paste it into your page, before </body>.

Need more than one button?

Paste the code once, then repeat only the <fuzz-button> tag.

Using a site builder?

Paste it into an Embed or custom code element.

Using React?

Load the script once, then use the tag like any element.

Want the same font?

Add Space Grotesk to your page. Without it, the button uses a system font.

Good to know

It works like a normal button: click, keyboard and touch. Listen for click as usual.

It needs WebGL2. Without it, you get a plain button. Slow devices get a thinner coat automatically.
